# Local data directory

This repository does not redistribute the official PestCLEF/EPOP data.

To rerun the full candidate-generation pipeline, obtain the official training, development, and test JSON files and the EPOP document text archive through the authorized CLEF/LifeCLEF/PestCLEF channels. Place your local copies in this directory or configure the paths in your own run script.

Only local users with appropriate data access should populate this directory. Do not commit the official data files to a public repository.
