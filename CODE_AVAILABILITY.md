# Code availability text for the manuscript

Suggested manuscript text after creating a public GitHub repository:

> Code availability. The source code used for candidate generation, selected-run construction, and submission validation is available at: [GitHub URL]. The repository contains the final selected submission CSV files, patch specifications, validation scripts, implementation notes, and validation reports. The official PestCLEF/EPOP raw data are not redistributed; users should obtain them through the official task channels and place them under the documented data directory.

If a Zenodo DOI is created, use:

> Code availability. The source code used for candidate generation, selected-run construction, and submission validation is available at [GitHub URL] and archived on Zenodo as [DOI]. The repository contains the final selected submission CSV files, patch specifications, validation scripts, implementation notes, and validation reports. The official PestCLEF/EPOP raw data are not redistributed; users should obtain them through the official task channels and place them under the documented data directory.
